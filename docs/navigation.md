# 위키 탐색 목록

컴파일 후 `workspace/drafts/<id>/_navigation/index.md`를 열면 페이지 목록, 참조 대상, 역방향 참조와 출처별 페이지를 확인할 수 있다.
`WikiNavigation`은 manifest와 실제 페이지 본문의 `[[id|제목]]` 또는 `[[id]]` 표기를 읽는다.
manifest에 있는 대상만 상대 링크로 연결하고 중복 참조는 한 번 표시한다.
존재하지 않는 대상은 목록에서 생략하지만 페이지를 수정하거나 발행을 차단하지 않는다.
Markdown AST 분석기가 아니므로 코드 블록 안의 위키 링크 표기도 참조로 인식할 수 있다.

페이지 이름이 `index`여도 충돌하지 않도록 목록을 별도 `_navigation` 하위 디렉터리에 둔다.
제목·출처 이름의 Markdown/HTML 표시 문자를 이스케이프한다.
목록은 검색 문서에 포함되지 않으며 모델 호출도 추가하지 않는다.

초안 페이지를 편집한 직후에는 초안 목록이 갱신되지 않는다. 발행 시 편집 내용을 읽어 새 발행본에 목록을 다시 생성한다.
초안 탐색 목록을 직접 고쳐도 그 수정은 발행본으로 복사되지 않는다. 기존 발행본은 유지된다.
탐색 목록이 없는 이전 초안도 발행할 수 있다.

이는 명시적 참조를 읽기 쉽게 제공하는 기능이다. 그래프 검색, 단계적 질의 추론, 의미적 사실 검증은 수행하지 않는다.
